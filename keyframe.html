Keyframe Animator

Unity plugin that enables UI animation using keyframes exported from After Effects

Technos used :

Context

This plugin was originally developed for an interactive film project built in Unity. The motion design was created in Adobe After Effects, but there was no seamless way to transfer and reproduce those animations inside Unity.

Overview

KeyFrame Animator for Unity bridges the gap between motion design and interactive development by importing transformation data from After Effects and applying it directly to Unity components. The plugin allows developers to map animation data such as position, rotation, and scale to UI elements, including buttons and other interactive components, ensuring that animations behave exactly as they were designed.

Demo

The motion data was tracked in After Effects and applied to the purple button, allowing it to move in sync with the animated object.
